# Library Management System - SQL Project

##  Project Overview
This project is a Library Management System developed using MySQL.
The project manages information about books, authors, library members, book borrowings, and fines. 
SQL queries are used to retrieve, analyze, and manage library data.

##  Technologies Used
- MySQL
- SQL
- csv files

##  Database Tables
The project contains the following tables:

1. **Authors** - Stores author information.
2. **Books** - Stores book details such as title, category, publication year, and available copies.
3. **Members** - Stores library member information.
4. **Borrowings** - Stores information about books borrowed by members.
5. **Fines** - Stores fine details for overdue books.
